# SethCohen/github-releases-to-discord

Automatically send a stylized Discord webhook of a GitHub Release description to a specified Discord channel.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/SethCohen/github-releases-to-discord](https://github.com/SethCohen/github-releases-to-discord).
